Este proyecto consiste en el desarrollo de un sistema de escritorio orientado a la administración de pedidos, productos y tareas logísticas para una tienda en línea. La aplicación fue desarrollada en Java utilizando el paradigma de Programación Orientada a Objetos (POO) y estructuras de datos implementadas manualmente, integrando una interfaz gráfica construida con Java Swing.
El objetivo principal del sistema es optimizar la gestión operativa de una tienda virtual mediante el registro de productos, administración de pedidos y control de tareas de preparación y envío, aplicando algoritmos y estructuras dinámicas.
A diferencia de aplicaciones convencionales que utilizan colecciones estándar de Java o bases de datos relacionales, este proyecto implementa desde cero diversas estructuras de datos personalizadas, permitiendo comprender de manera práctica el comportamiento interno y la eficiencia de cada una de ellas.

El sistema incorpora funcionalidades completas para la administración del flujo operativo de una tienda:
Gestión de productos mediante listas doblemente enlazadas.
Registro y administración de pedidos utilizando árboles binarios de búsqueda (BST).
Control de tareas de preparación y despacho mediante colas enlazadas FIFO.
Historial de acciones y funcionalidad de deshacer utilizando pilas enlazadas.
Persistencia de información mediante archivos XML.
Sistema de autenticación con roles de usuario.
Interfaz gráfica intuitiva desarrollada con Java Swing.

La arquitectura del proyecto se encuentra organizada por capas y paquetes especializados, separando claramente:
Modelos de datos.
Servicios de negocio.
Persistencia XML.
Interfaces gráficas.
Implementaciones de estructuras de datos.

Además, el sistema implementa operaciones fundamentales como:
Inserción, búsqueda y eliminación de productos.
Creación y actualización de pedidos.
Filtrado por cliente y estado.
Gestión de estados de pedidos.
Procesamiento secuencial de tareas.
Funcionalidad de deshacer acciones realizadas sobre pedidos.
Desde el enfoque académico, el proyecto representa una aplicación integral de estructuras de datos dinámicas y algoritmos clásicos, evidenciando cómo cada estructura puede resolver necesidades específicas dentro de un sistema real.
